# OSRS Companion

This repository now holds both the GitHub Pages PWA and the maintained Apps Script backend source.

- `index.html`, `manifest.webmanifest`, `sw.js`: public PWA frontend.
- `apps-script/Code.gs`: backend source-of-truth for automated code maintenance.
